# SafeSpeak — Child Safeguarding, Wellness & Recovery Ecosystem

> **Trust Before Disclosure. Support Beyond Reporting.**
>
> A child-centred safeguarding, wellness, and recovery ecosystem designed to bridge the gap between a child's fear of speaking up and the help they deserve.

---

## 🌟 Overview & Purpose

SafeSpeak is an AI-assisted child safeguarding and wellness platform that combines conversational AI, confidential reporting, physical school kiosks, safeguarding workflows, counselling connections, and recovery support into one integrated system.

Our mission is to ensure that no child's concern is overlooked simply because they were afraid to express it. Traditional systems often begin with the demand *"What happened?"*; SafeSpeak begins with the supportive question: *"Do you feel safe enough to talk?"*

## 🏛️ CCPRB Governance Framework

**CCPRB** stands for the **Central Child Protection Response Board**.

> [!IMPORTANT]
> **Regulatory Clarification:** CCPRB is SafeSpeak's **proposed independent safeguarding oversight and escalation framework**. It is an internal project governance concept and is **not** an existing statutory government authority, police department, or court. It does not possess independent judicial or punitive powers; rather, it provides independent oversight and ensures reports involving school personnel or serious child abuse reach verified external statutory authorities (such as Child Welfare Committees, Special Juvenile Police Units, and POCSO courts) without being suppressed or ignored.

### Proposed CCPRB Structure:
1. **Safeguarding Review**: Professional case assessment and triage.
2. **Response Coordination**: Conflict-free external routing.
3. **Accountability**: Response tracking and SLA monitoring.
4. **Quality & Review**: Workflow auditing and ethical oversight.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended; v20+ supported)
- npm or pnpm or bun

### Installation
```bash
# Clone the repository
git clone https://github.com/Kavexa/safespeak_reporting_FINAL.git
cd safespeak_reporting_FINAL

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
